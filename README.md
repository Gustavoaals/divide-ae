# Divide Aê 🏠

Sua casa, nossa organização.

O Divide Aê é uma plataforma web desenvolvida para facilitar a organização e a administração de moradias compartilhadas, como repúblicas estudantis, casas e apartamentos divididos entre moradores.

A proposta é centralizar em um único ambiente as principais atividades da convivência, permitindo que os moradores gerenciem despesas, organizem tarefas domésticas, acompanhem compras, solicitem manutenções e compartilhem informações.

### Funcionalidades

- Gestão de residências e moradores.
- Controle de despesas e pagamentos.
- Organização e distribuição de tarefas.
- Sistema de pontuação e conquistas.
- Controle de despensa e lista de compras.
- Comunicação entre moradores.
- Solicitações de manutenção.

### Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL

### Objetivo

Desenvolver uma aplicação funcional, responsiva e segura, aplicando conceitos de desenvolvimento web, modelagem de banco de dados, integração com APIs e controle de acesso.
